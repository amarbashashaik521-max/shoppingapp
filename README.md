# 🛍️ ShopEase – E-Commerce Web Application

ShopEase is a responsive e-commerce web application developed using HTML, CSS, and JavaScript.

This project was developed as the **Task 5 Capstone Project** during my Web Development Internship at **ApexPlanet Software Pvt. Ltd.**

## 🚀 Features

- 🛒 Add products to cart
- ➕ Increase or decrease product quantity
- ❌ Remove products from cart
- 💰 Automatic cart total calculation
- 🔍 Search products by name
- 🏷️ Filter products by category
- 💾 Cart data stored using LocalStorage
- 📱 Responsive design for desktop, tablet, and mobile
- ⚡ Lazy loading for product images
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
- CSS Grid
- Media Queries
